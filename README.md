# 약사대전 — Pharmacist Fortress

약사 캐릭터들이 약물·의약품을 무기로 싸우는 2D 턴제 포격 대전 웹게임입니다.
설치·로그인 없이 브라우저(PC/모바일)에서 바로 플레이할 수 있습니다.

## 현재 단계: 1단계 — 핵심 게임 (플레이 가능)

- 캐릭터 10종: 팽·구·방·철·석·동·용·사공·조·두약사 — 캐릭터 설정 시트의 인게임 스프라이트(대기/전투/공격, `public/chars2`, `tools/cut_sprites.py`)
- 캐릭터마다 기본탄(무제한)·특수탄(사용 후 3턴 대기)·필살기(게이지 100) 3종 — 연사, 부채꼴, 유도, 분열, 화살비, 낙뢰, 레이저, 드래곤 스윕, 순간이동, 자가 회복 등
- 맵 6종 (일반 포트리스 대비 약 2배 폭):
  🌿 약초의 숲 · ❄️ 빙결 설산(나무 다리, 얼어붙은 호수) · 🌙 달 기지(저중력·무풍, 동굴) ·
  🏴‍☠️ 해적의 만(바다, 부두, 암초) · 🌋 화산 연구소(용암 바다) · ☁️ 하늘의 약국(공중섬)
- 맵별 중력/바람 배율, 물·용암 추락 판정, 재질별 지형 표현(흙·눈·얼음·나무·금속·현무암)
- 이동(턴당 거리 제한) · 각도 · 파워 충전 발사 · 바람 · 30초 턴 제한
- 픽셀 단위 지형 파괴 + 낙하 + 맵 밖 추락 판정
- 거리별 피해 감소, 필살기 게이지(최대 100)
- AI 대전(쉬움/보통/어려움 — 실제 탄도 시뮬레이션 기반), 같은 기기 2인 대전
- 폭발/섬광/충격파/파편/연기 이펙트, 카메라 추적, 합성 사운드(BGM/효과음 볼륨 분리)
- 모바일 터치 컨트롤(왼쪽 이동, 오른쪽 각도·발사), 전체화면

## 조작법

| 입력 | 동작 |
|---|---|
| ← → / A D | 이동 · 방향 전환 |
| ↑ ↓ / W S | 발사 각도 |
| 스페이스 (누르고 떼기) | 파워 충전 후 발사 |
| 1 / 2 / 3 | 기본탄 / 특수탄 / 필살기 |
| 드래그 | 맵 둘러보기 |
| Esc | 일시정지 · 설정 |

## 아키텍처

```
src/core/   순수 TypeScript 게임 로직 (렌더링 의존성 없음 → 4단계에서 서버가 그대로 실행)
  constants.ts  물리/규칙 상수
  terrain.ts    1px 마스크 기반 파괴 지형 (렌더링·충돌이 같은 데이터 사용)
  physics.ts    고정 타임스텝 탄도(등가속도 정확 적분) + 0.5px 간격 연속 충돌 검사, 캐릭터 이동/낙하
  game.ts       턴/페이즈 상태 머신, 폭발·피해·게이지·승패 판정, 이벤트 큐
  ai.ts         실제 물리로 탄착점을 탐색하는 AI
  mapgen.ts     시드 기반 맵 생성 (사칙연산만 사용 → 엔진 간 동일 결과)
src/game/   Phaser 3 렌더링 (씬, 청크 단위 지형 렌더러, 이펙트, 픽셀아트 생성, 사운드)
src/ui/     DOM HUD · 메뉴 · 결과 화면
tests/      Vitest 자동화 테스트
```

결정론 설계: 시뮬레이션은 120Hz 고정 틱으로만 진행되며, 삼각함수는 정수 각도 테이블(1e-9 반올림)로,
지형 파괴 모양은 사칙연산만으로 계산합니다. 같은 입력이면 어느 기기에서나 같은 결과가 나옵니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 자동화 테스트 (탄도·CCD·지형 파괴·낙하·턴·전체 게임 회귀)
npm run build    # dist/ 정적 빌드
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 자동으로 수행합니다.
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정)

## 로드맵

1. ✅ 핵심 게임
2. 그래픽 고도화 (캐릭터 애니메이션 프레임 확장, 이펙트 스프라이트, 사운드)
3. 콘텐츠 확장 (캐릭터 8종+ · 맵 6종 · 캐릭터별 필살기 · 선택 화면)
4. ✅ 온라인 멀티플레이 (Node.js + WebSocket, 서버 권한 판정)
5. 최적화 및 배포

### 캐릭터 이미지 교체

`tools/cut_chars.py`가 레퍼런스 시트에서 캐릭터를 잘라 흰 배경·이름판을 제거하고 `public/chars/<id>.png`(높이 120px)로 저장합니다.
새 일러스트로 바꾸려면 같은 이름의 PNG(투명 배경, 발이 이미지 맨 아래)를 덮어쓰면 됩니다.

## 그래픽 개선 (2026-11-02)

전후 비교: `docs/compare/moon_before_after.png`

- **지형 렌더러 재작성** (`src/game/terrainView.ts`): 2D 다중 옥타브 노이즈 + 5단계 포스터라이즈 암석층, 지층·균열·박힌 바위,
  실시간 조명(1px 외곽선, 위가 트인 면 하이라이트, 아래가 트인 면 그림자) → 폭발로 생긴 단면도 같은 질감·조명으로 표시
- **달 기지 지형** (`src/core/mapgen.ts`): 거친 바위 능선, 지표 크레이터, 돌출 바위, 불규칙 동굴(46개 → 6쌍)
- **우주 배경** (`src/game/spaceBg.ts`): 절차적 픽셀아트 성운·별·지구(대륙/구름/도시 불빛/대기광)·소행성 3층·우주정거장(포탑·점멸등),
  별 반짝임·별똥별·우주선 통과, 원경→근경 패럴랙스
- **캐릭터**: 240px로 재추출, 화면 크기 33% 확대(월드 80px), 접지 그림자, 발밑 이름판/체력바, 무기 1.5배
- **필터링**: 일러스트(캐릭터·배경 사진)는 LINEAR, 픽셀아트(지형·무기·이펙트)는 NEAREST, 정수 줌(고해상도 데스크톱 3배)
- **UI**: 네이비/블루 패널 HUD — 바람·맵 이름·플레이어 카드, 턴/시간, 미니맵(클릭 시 해당 위치 보기), 각도 다이얼,
  무기 슬롯(기본탄/필살기), TIME, 체력·파워·이동 바, 턴 넘기기/설정/나가기, 무기발사(FIRE) 버튼

## 온라인 대전

- 계정 없이 닉네임으로 공개 대기실 생성/입장 (2–8명).
- 개인전 또는 BLUE/RED 팀전, 방장 별표·강퇴·퇴장 시 방장 승계.
- 먼저 준비한 플레이어가 캐릭터를 선점하며, 설정 변경 시 준비가 해제됩니다.
- 방장을 포함한 전원 준비 및 팀전 양 팀 참여를 서버에서 확인한 뒤 시작합니다.
- 서버가 120Hz로 게임을 판정하고 20Hz WebSocket 묶음을 전달합니다. 브라우저는 승인된 입력만 동일한 순서로 재생합니다.
- 전투 중 연결 종료/퇴장은 항복 처리하며, 다시 연결한 뒤 새 대기실에 참여할 수 있습니다.
- 대기실은 메모리에서 운영하므로 서버가 재시작되면 초기화됩니다. 배포는 진행 중인 경기가 없을 때 권장합니다.

개발: `npm run server` (3001), `npm run dev`. `public/online-config.json`에 WebSocket 주소를 설정합니다.
운영: Render Peter's workspace의 `pharmacist-fortress-online` (Singapore, Free, 단일 인스턴스). `fortress-online` 브랜치에서 `npm ci` → `npm run server`로 배포합니다. 서버 변경 시 이 브랜치도 최신 상태로 유지해야 합니다. 프런트엔드는 기존 GitHub Pages의 `main` 배포를 사용합니다.
서버 상태: https://pharmacist-fortress-online.onrender.com/health · 무료 서버는 유휴 상태에서 잠들며 첫 접속에 약 1분이 걸릴 수 있습니다. 클라이언트는 최대 90초 동안 서버 준비를 기다립니다.
Dockerfile / railway.json은 다른 호스팅으로 옮길 때 사용할 수 있습니다.
게임 규칙이나 네트워크 메시지를 변경할 때는 서버와 클라이언트를 함께 배포하고 `src/online/protocol.ts`의 버전을 갱신합니다.
테스트: `npm test`에는 방장 권한, 준비 선점 경쟁, 팀 조건, 강퇴, 입력 검증, 서버/클라이언트 지형 동기화 검사가 포함됩니다.
